# FileEncryptor 🔐

- FileEncryptor - это консольная утилита для шифрования и дешифрования файлов, написанная на языке Zig. Проект создан в рамках практики по криптографии и демонстрирует использование современного аутентифицированного шифрования (AEAD) на примере алгоритма XChaCha20-Poly1305

*Утилита работает с файлами произвольного размера, использует отдельный файл ключа и сохраняет в зашифрованном файле все необходимые компоненты (nonce и тег аутентификации) для последующей корректной расшифровки*

## Возможности ✨

- Симметричное шифрование файлов с использованием XChaCha20-Poly1305 (AEAD).
- Два режима работы: `enc` (шифрование) и `dec` (дешифрование).
- Аутентификация данных: тег Poly1305 гарантирует, что зашифрованный файл не был изменён.
- Безопасный nonce: для каждого шифрования генерируется случайный 24-байтовый nonce (XChaCha20 позволяет безопасно использовать случайные nonce).
- Простой интерфейс командной строки с минимальным набором аргументов.
- Кроссплатформенность за счёт использования стандартной библиотеки Zig.

## Требования 📋

- Установленный компилятор **Zig** (проект разработан с использованием `std.crypto`, входящей в стандартную библиотеку Zig).
- Ключевой файл длиной ровно **32 байта** (256 бит) - требуется для обоих режимов.

## Установка и запуск ⚙️

1. Клонируйте репозиторий: 
```bash
git clone https://github.com/the-wlfrm/FileEncryptor.git
cd FileEncryptor 
```

2. Убедитесь, что в системе доступен Zig. Запуск осуществляется напрямую через `zig run`:
```bash
zig run src/main.zig -- [режим] [файл_ключа] [входной_файл] [выходной_файл]
```

## Использование 👨‍💻
### Шифрование файла
```bash
zig run src/main.zig -- enc secret.key plaintext.txt encrypted.txt
```
- `enc` - режим шифрования.
- `secret.key` - путь к файлу с 32-байтовым ключом.
- `plaintext.txt` - исходный файл.
- `encrypted.txt` - результирующий зашифрованный файл.

После успешного завершения выводится сообщение:
`Файл успешно зашифрован! (encrypted.txt)`

### Дешифрование файла
```bash
zig run src/main.zig -- dec secret.key encrypted.txt decrypted.txt
```
- `dec` - режим дешифрования.
- `secret.key` - тот же ключ, что использовался при шифровании.
- `encrypted.txt` - зашифрованный файл.
- `decrypted.txt` - восстановленный исходный файл.

При успехе выводится: 
`Файл успешно расшифрован! (decrypted.txt)`

> **Важно:** для шифрования и дешифрования должен использоваться один и тот же ключевой файл. Потеря ключа делает восстановление данных невозможным.

## Формат зашифрованного файла 📦

Зашифрованный файл имеет следующую структуру:

| Поле          | Размер (байт)              | Описание                      |
|---------------|----------------------------|-------------------------------|
| `nonce`       | 24                         | Случайный nonce для XChaCha20 |
| `ciphertext`  | = размер исходного файла   | Зашифрованные данные          |
| `tag`         | 16                         | Тег аутентификации Poly1305   |

Именно в таком порядке данные записываются при шифровании и читаются при дешифровании. Если файл короче 40 байт (24 + 16), дешифрование завершится ошибкой `EncryptedFileTooShort`.

## Безопасность 🔒

- **XChaCha20-Poly1305** — это схема аутентифицированного шифрования с присоединёнными данными (AEAD), которая одновременно обеспечивает конфиденциальность и целостность. Она устойчива к атакам на основе подобранного шифротекста и широко рекомендуется для безопасного шифрования файлов.
- **24-байтовый nonce** позволяет генерировать его случайно для каждого файла без практического риска коллизий, что упрощает безопасное использование.
- **Ключ должен храниться отдельно** от зашифрованных данных. Утилита не занимается управлением ключами и не защищает ключевой файл — это ответственность пользователя.
